# 🍜 Marugame Seimen Website

> A restaurant website concept for **Marugame Seimen**, the Japanese udon chain known for freshly made noodles and self-service tempura counters.
> Built as a class project for **ABP Business and Cultural**.

---

## 📌 Project Overview

This project is a responsive website that introduces Marugame Seimen to customers. Visitors can browse the menu, learn about the brand's story, find outlet locations, and get in touch with the restaurant.

**Goals of the project:**
- Present the brand with a clean, Japanese-inspired design
- Make the menu easy to browse on both desktop and mobile
- Practise front-end web development skills learned in class

---
